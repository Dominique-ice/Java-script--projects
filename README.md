### js-functions-lab.js
Four JavaScript functions built during the Functions 
section of FreeCodeCamp:

- maskEmail — masks the username of any email address
- getLoanMessage — checks loan eligibility based on 
  annual income and credit score
- convertCtoF — converts Celsius to Fahrenheit

### calculator.js
A command-line calculator with four arithmetic operations:
- calculateSum — adds two numbers

- calculateQuotient — divides two numbers with division by zero protection

## nested-conditionals-lab.js

Three JavaScript functions built during the Functions section of FreeCodeCamp, focused on nested if/else logic:

- isLeapYear — checks if a year is a leap year using nested conditionals
- truncateString — shortens a string to a given length and appends "..."
- confirmEnding — checks if a string ends with a given target string without using .endsWith()

### Concepts practiced
- Nested if/else statements
- Modulus operator (%)
- String slicing (.slice())
- Boolean return values
- Template literals

Added: July 2, 2026
